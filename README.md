# ScreenCapturer

ScreenCapturer 是一款电脑桌面截图，编辑，钉图的软件。

### 主要功能

- 通过快捷键快速截图，截图后可以对图片进行编辑，软件实现了多种常用编辑工具。
- 编辑后可以对图片做多种操作，比如钉在桌面、保存、复制到剪切板等。

### 从源码构建

本软件代码使用C++ + Qt6编写，通过Qt Creator打开根目录的CMakeLists.txt即可编译。

目前支持Windows和MacOS系统。
